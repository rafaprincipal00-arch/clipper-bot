Antes de pulsar

  1. YouTube: proyecto en Google Cloud con YouTube Data API v3 y cliente OAuth web con redirect https://<este-dominio>/api/oauth/youtube.
  2. TikTok: app en developers.tiktok.com con Login Kit + Content Posting API (Direct Post), scopes user.info.basic,video.publish,video.upload.
  3. Instagram: cuenta profesional (Creator) y app de Meta con «Instagram API with Instagram Login», permisos instagram_business_basic,instagram_business_content_publish.
